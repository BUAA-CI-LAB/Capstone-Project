# 第九周实验：Serving 配置对比

## 实验任务

在课程的 **DGX Spark** 上，基于已有的本地模型服务，**比较不同 batching、并发与 context 配置，提交 Serving 对比记录**。

## 任务要求

1. 围绕 batching、客户端并发和上下文长度，选择不同配置进行对比，记录配置设置与实际运行结果。
2. 结合吞吐、首 token 延迟（TTFT）、生成阶段每 token 耗时（TPOT）等指标，分析配置变化对服务性能的影响。
3. 根据实验结果，为本组 Agent 给出配置建议，并简要说明理由。

模型、测试工具、具体参数取值和实验组织方式可以自行选择，在报告中说明比较条件即可。

## 提交内容

提交一份简短实验报告，说明实验设置、对比结果和主要结论。可以用表格、图表或截图展示实际结果。

**报告采用 Word、PDF 或 Markdown 格式均可。** 截止时间与提交入口以课程通知为准。

## 简单实验报告格式参考

### 1. 基本信息

填写实验名称、姓名与学号；小组完成时注明组号和成员。

### 2. 实验设置

简要介绍使用的模型、运行环境和测试工具，列出参与对比的 batching、并发与 context 配置。说明各组对比主要改变了什么，以及使用了怎样的测试输入，让读者能够理解结果是在什么条件下得到的。

### 3. 实验结果

用表格整理各组配置对应的主要测量结果，注明指标单位和统计方式，也可以配合图表或截图展示变化趋势。例如：

| 配置 | 主要设置 | 输出吞吐（tokens/s） | TTFT（ms） | TPOT（ms/token） | 备注 |
| --- | --- | --- | --- | --- | --- |
| A | 待填 | 待填 | 待填 | 待填 | 待填 |
| B | 待填 | 待填 | 待填 | 待填 | 待填 |
| … | … | … | … | … | … |

表格可按实际实验调整；设置较多时，可以把配置说明与结果分成两张表。备注中可记录测试时观察到的现象或异常。

### 4. 分析与结论

结合数据说明 batching、并发和上下文长度变化带来的主要影响，讨论吞吐与延迟之间的取舍及可能原因。最后，为本组 Agent 推荐一套配置，并说明推荐理由和适用场景。

如果结果差异不明显、波动较大或出现测试失败，也可以如实讨论，无需预设某种配置一定更好。

以上结构可按实际实验调整。
