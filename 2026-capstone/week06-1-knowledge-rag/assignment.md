# 第六周实践：完成 Agent v1

## 实践目标

尝试为自己的 Agent 接入 **Memory、至少两种 Tool 和一个小型知识库**，探索它们可以帮助 Agent 完成什么任务。

**提供的[参考代码](code/README.md)只是一个非常简单的示例，用于帮助理解基本流程。** 可以在此基础上按自己的想法做各种修改和拓展，也可以继续已有项目，或独立设计实现，不必依托这份参考代码。

应用场景、资料、工具和实现方式可以自行选择。不要求采用与参考示例相同的模型、框架、记忆方式或检索流程，鼓励自由尝试。

## 可以尝试的方向

- 换成自己的课程资料、实验说明或项目文档，让助手处理实际问题。
- 添加有用的工具，或者调整 Agent 使用工具的方式。
- 尝试保存、更新或选择记忆，观察它怎样影响后续交互。
- 调整资料切分、检索或回答方式，比较实际表现。

以上仅用于启发思路，可以选择其他方向。不规定拓展数量、统一测试场景、资料规模、成功率或展示效果。

## 提交内容

- **代码及必要的配套文件**：包含运行说明、依赖说明，以及复现示例所需的小型资料或获取方法。无需提交模型权重、虚拟环境和下载缓存。
- **一份简短说明**：可以写在 `README.md` 或 `report.md` 中，注明姓名、学号，介绍想解决的问题、Memory / Tool / 知识库的使用方式、自己做了哪些尝试、怎样运行，以及实际效果和遇到的问题。
- **可选的展示材料**：可以附有代表性的运行记录或截图，形式与数量自行安排。

不限定项目目录结构，也不要求逐项填写固定报告模板。复用参考代码、已有成果或开源工具时，注明所用来源和自己修改的部分即可。保留真实运行结果，效果未达到预期也可以如实讨论。
