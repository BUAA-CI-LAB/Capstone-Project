# 第一周作业：Qwen 模型推理

## 任务

1. 使用 Transformers 运行 Qwen2.5-1.5B-Instruct 或 Qwen2.5-3B-Instruct，CPU 或 GPU 均可。
2. 自选一个问题，记录输入、模型输出、单次推理时间及实际生成 token 数。
3. 使用 `--debug` 打印 hidden states 的形状和部分数值，保存运行结果。

按 [模型下载说明](README.md#模型下载) 下载后运行：

```bash
python qwen_inference.py --model ./models/Qwen2.5-1.5B-Instruct --device cpu --max-new-tokens 32 --debug --output results/run.json
```

## 提交内容

- 推理脚本（`.py`）。
- 运行结果（JSON 或完整终端日志），包含输入、输出、推理时间、token 数，以及 hidden states 的形状和部分数值。
- 按下方模板填写 `提交说明.md`，与脚本、运行结果一起提交。

无需提交模型权重和虚拟环境。
