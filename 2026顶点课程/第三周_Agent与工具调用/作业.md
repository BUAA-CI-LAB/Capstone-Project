# 第三周作业：Agent v0 —— 调参对比与调用链分析

## 任务

1. 跑通 `agent_v0.py`：`python agent_v0.py --selftest`，全部 PASS。
2. **固定同一个任务**（默认的"读取 test_report.txt，计算测试通过率"，也可以自选一个同样需要调用工具才能完成的任务，但 5 次运行都用这一个），**每次只调整一项运行参数，连续跑 5 次**，可调整的方向包括：
   - 贪心解码 vs 开 `--sample` 采样
   - 采样时的 `--temperature`/`--top-p`/`--top-k`
   - 切换模型规模（比如 Qwen2.5-1.5B-Instruct vs 3B/7B，如果你有条件跑更大的模型）
   - 也可以是这几项的组合（比如"7B + 采样" vs "7B + 贪心"）
   每次运行都保存 `results/*.json`，文件名能看出对应哪一组参数。
3. **调用链分析**：从这 5 次里选出至少 2 条有代表性的 trace（建议一成功一失败，或者两条失败原因不同的），逐步说明模型每一步的 `raw`/`decision`/`observation`，解释为什么在这个参数组合下得到这个结果；再横向对比 5 次的 `status`，说说你观察到的规律（比如"换大模型后 read_file 的路径就用对了""开采样后同样的参数有时对有时错"）。
4. **（可选加分）自选一项方法上的小拓展**，方向不限，比如：给 hf 后端加生成停止条件、改 Prompt（约束输出格式/禁止某些表达方式）、加一个新工具——完成一项小体量尝试即可，不要求做全套；把改了什么、为什么改、跑出来什么效果，完整记录下来。结果没达到预期也如实记录。

这周的重点是通过"调参数、看 trace"理解 Agent Loop 每一步在做什么、哪些因素会影响真实模型的表现。真实模型的成功率不作为评分依据，评分主要看参数调整是否合理、trace 分析是否清晰。
